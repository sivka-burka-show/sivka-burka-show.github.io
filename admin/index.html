Управление сайтом

Войти через GitHub
  1. Выберите раздел и сохраните изменения в редакторе. Ссылки на билеты для отдельных сеансов находятся в разделе «Афиша и билеты».
  2. Откройте предпросмотр после сборки черновика. Проверьте фотографии, даты и кнопки покупки.
  3. В редакторе нажмите «Опубликовать на сайте».
